# Multi-Agent AI Lab

My beginner journey building multi-agent AI systems with Python.

## About This Project

This repository contains my practical experiments as I learn to design and build multi-agent AI systems.

## First Project: Simulated Multi-Agent Workflow

The first project demonstrates how specialised agents can collaborate through a central orchestrator.

### Agents

- **Researcher:** Provides research findings.
- **Analyst:** Analyses the findings.
- **Reviewer:** Evaluates the analysis.
- **Orchestrator:** Coordinates the agents and produces the final report.
